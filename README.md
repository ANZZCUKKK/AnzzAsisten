## 🔄 Cara Kerja

```

Copy teks dari aplikasi apapun
↓
AnzzAsisten deteksi clipboard
↓
Notifikasi "Memproses..." muncul
↓
AI memproses teks
↓
Jawaban masuk clipboard + notifikasi selesai
↓
Paste jawaban di aplikasi mana pun

```

## 🛠️ Instalasi

### Prasyarat
- [Tasker](https://play.google.com/store/apps/details?id=net.dinglisch.android.taskerm)
- [AutoTools](https://play.google.com/store/apps/details?id=com.joaomgcd.autotools)

### Langkah Instalasi
1. Import file `AnzzAsisten.prf.xml` ke Tasker
2. Ganti `YOUR_API_KEY_HERE` dengan API key asli
3. Selesai! Copy teks untuk test.
